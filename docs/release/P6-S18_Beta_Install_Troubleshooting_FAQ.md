# Mozzy Beta Install Troubleshooting FAQ

## 1. I cannot find the invitation email
- Check spam / promotions folder.
- Search for Firebase App Distribution.
- Confirm the email address used for testing.

## 2. Android blocks APK installation
- This can happen because the app is distributed privately.
- Allow installation from Firebase App Tester or browser when prompted.

## 3. Google login fails
Please send:
- Screenshot
- Phone model
- Android version
- Time of failure

## 4. App opens but there is no data
- Some areas may have limited beta data.
- This is okay.
- Please still submit feedback.

## 5. Chat looks empty
- Empty chat list is okay.
- Infinite loading is not okay.
- Please report if it keeps loading forever.

## 6. Some features show Coming Soon
- This is expected for Beta 1.
- Auction, Clubs, Lost & Found, POM, Real Estate, Stores, Together are disabled.
