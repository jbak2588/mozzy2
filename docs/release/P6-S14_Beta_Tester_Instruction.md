# Mozzy Android Beta 1 Tester Instruction

## 1. 설치 방법
- Firebase App Distribution 초대 이메일 확인
- Android에서 링크 열기
- Firebase App Tester 앱 설치가 필요할 수 있음
- APK 설치 허용

## 2. 테스트해야 할 기능
1. Google Login
2. Smart Feed
3. Marketplace
4. News
5. Jobs
6. Pesan / Chat
7. Feedback
8. Account Settings
9. Logout
10. Account Deletion 화면 진입

## 3. 주의 사항
- 실제 결제 금지
- 결제는 sandbox only
- 일부 기능은 Coming Soon 표시가 정상
- 개인정보/비밀번호/신분증 번호를 Feedback에 입력하지 말 것

## 4. 버그 보고 방법
버그 보고 시 아래를 함께 전달:
- 기기 모델
- Android 버전
- 발생 화면
- 발생 시간
- 스크린샷
- 재현 단계

## 5. Known Limitations
- iOS는 아직 테스트 대상 아님
- 일부 모듈은 Beta 1에서 비활성화
- Storage 이미지 완전 삭제는 Beta 2 이후
